# Les Chroniques d'Eldoria

Un RPG solo en pixel art pour Windows : trois classes, combats au tour par tour, villages à visiter,
forêts, mines et crypte à explorer, forge, panoplies et une grande cité royale.

## Jouer

1. Ouvre la page **[Releases](../../releases/latest)**.
2. Télécharge **ChroniquesEldoria.exe**.
3. Lance-le : aucune installation n'est nécessaire.

Le jeu vérifie au démarrage si une nouvelle version est disponible et se met à jour tout seul.
Les sauvegardes sont conservées dans `%APPDATA%\ChroniquesEldoria`.

Windows peut afficher un avertissement « Windows a protégé votre ordinateur » la première fois :
clique sur « Informations complémentaires » puis « Exécuter quand même ».
