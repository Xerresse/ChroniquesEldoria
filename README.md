# Les Chroniques d'Eldoria

Un RPG solo en pixel art, dans un Japon de légende, pour **Windows, Mac et Linux** : trois classes,
combats au tour par tour, villages à visiter, forêts, mines, crypte et montagne sacrée à explorer,
forge, panoplies, monstres d'élite, bestiaire et succès. En français et en anglais.

## Jouer

Ouvre la page **[Releases](../../releases/latest)** et télécharge le fichier de ton système :

| Système | Fichier |
|---|---|
| Windows | **ChroniquesEldoria.exe** |
| Mac à puce Apple (M1, M2, M3...) | **ChroniquesEldoria-mac-arm.zip** |
| Mac à processeur Intel | **ChroniquesEldoria-mac-intel.zip** |
| Linux | **ChroniquesEldoria-linux.tar.gz** |

- **Windows** : lance le fichier, aucune installation n'est nécessaire. Windows peut afficher
  « Windows a protégé votre ordinateur » la première fois : clique sur « Informations complémentaires »
  puis « Exécuter quand même ».
- **Mac** : décompresse le fichier et glisse *ChroniquesEldoria* dans le dossier Applications.
  L'application n'est pas signée par Apple : au premier lancement, fais **clic droit > Ouvrir**, puis
  confirme (une seule fois). Pour savoir quel Mac tu as : menu Pomme > *À propos de ce Mac*.
- **Linux** : décompresse l'archive puis lance le fichier `ChroniquesEldoria`.

Le jeu vérifie au démarrage si une nouvelle version est disponible et se met à jour tout seul.
Les sauvegardes sont conservées dans `%APPDATA%\ChroniquesEldoria` (Windows),
`~/Library/Application Support/ChroniquesEldoria` (Mac) ou `~/.local/share/ChroniquesEldoria` (Linux).
